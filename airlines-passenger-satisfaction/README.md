# Airlines Passenger Satisfaction

Exploratory data analysis of airline passenger satisfaction.

## Project structure

```text
data/raw/          Original, unchanged datasets
data/processed/    Cleaned and transformed datasets
notebooks/         EDA notebooks
src/               Reusable analysis code
reports/figures/   Exported charts and figures
```

## Getting started

1. Place the source dataset in `data/raw/`.
2. Install dependencies with `pip install -r requirements.txt`.
3. Create notebooks in `notebooks/` and keep reusable functions in `src/`.
